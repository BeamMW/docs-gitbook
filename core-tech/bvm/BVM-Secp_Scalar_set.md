# Env::Secp_Scalar_set

```C++
void Secp_Scalar_set(Secp_scalar& dst , uint64_t val);
```
Sets `dst` to the given 64-bit value `val`

## Parameters
* `dst `: destination scalar object handle (opaque pointer)
* `val` : value to be set into scalar


## Return value
* none

* none
