# Env::get_SlotImage

```C++
void get_SlotImage(Secp_point& res, uint32_t iSlot)
```
Loads the image of the nonce from given slot. Slot should be initialized via [SlotInit](SlotInit)

## Parameters
* `res` : image of the nonce
* `iSlot` : nonce slot number


## Return value
* none

* none
