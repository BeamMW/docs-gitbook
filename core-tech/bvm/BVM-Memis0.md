# Env::Memis0

```C++
uint8_t Memis0(const void* p , uint32_t size);
```
Checks if `size` bytes pointed by `p` are zeroed

## Parameters
* `p` : pointer to the memory buffer
* `size`  : number of bytes to examine

## Return value
* 1 if the specified memory region is entirely set to 0
* 0 otherwise

* none
